## Usage Notes

- All prompts should be generated with consistent lighting, palette, and style
- Photography prompts: use "realistic photography" mode in Recraft
- Logo/vector prompts: use "vector" or "illustration" mode
- Icon prompts: use "icon" mode
- Packaging prompts: use "mockup" mode if available
- Maintain the same dark espresso background across all product shots for visual cohesion
- Gold accents should appear sparingly — never as flashy gradients
